# RunLoad Record Input UI Prototype V0.6 — Header/Footer density

- Mobile header is no longer sticky while scrolling.
- Header height is slightly reduced.
- Bottom save bar remains fixed for reachability, but its overall height is reduced.
- Draft and save buttons are smaller in height and radius.
- Mobile content bottom padding is reduced to match the smaller action bar.
- Toast position is adjusted upward relative to the smaller footer.
- V0.5 date-control structure is preserved.
