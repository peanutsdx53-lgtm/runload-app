# Record Navigation Continuity V0.12

Date: 2026-09-18
Status: PROTOTYPE ONLY / FORMAL CURRENT UNCHANGED

Decision:
- Record must not remove the app-level primary navigation.
- Users must be able to leave Record for Home, Result, History, or later More functions without first completing the record.
- Save actions and navigation actions must remain visually separate.

Mobile:
- Primary navigation stays at the bottom.
- Draft / Save bar sits directly above primary navigation.
- In Record sub-input screens (body record / shoes), the primary navigation remains visible while the parent Record save bar is not exposed.

Desktop:
- Existing in-content save controls remain.
- Primary navigation remains available at the bottom of the viewport.

Synchronized prototype set:
- Home V0.4
- Record V0.12
- Result V0.12
- History V0.11
- Plan V0.3
- Simulation V0.8
- Course Settings V0.10
- GPX V0.11

Unchanged:
- Record 1 -> 2 -> 3 -> 4 hierarchy.
- Input meaning and required/optional boundaries.
- ROF-J meaning.
- Course / GPX unknown-value handling.
- Formal Current V1.16 / App V1.5R2.
- Notebook remains absent.
