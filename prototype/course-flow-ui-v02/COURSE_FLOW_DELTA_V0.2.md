# Course Settings V0.2

- Adds optional GPX assist entry to local GPX V0.3.
- Beginner slope entry no longer requires percentage knowledge.
- Easy mode: total distance + uphill/downhill distance -> shares.
- Optional distance + elevation difference -> representative grade.
- Detailed mode supports up to 5 sections with type, distance, optional elevation difference.
- Unknown values remain unknown; no inferred slope is inserted.
- New-course duplicate names trigger a choice: use existing course or save as a separate course.
- No automatic overwrite or merge.
- Formal Current unchanged.
