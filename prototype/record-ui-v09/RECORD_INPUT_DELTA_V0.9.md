# RunLoad Record Input UI Prototype V0.9 — Unified Step Flow

- Step 1 is explicitly numbered so the visible flow is 1 → 2 → 3 → 4.
- The fatigue entry is no longer a separate card above the required input.
- Fatigue is shown as an optional sub-action inside Step 1.
- The fatigue scale sheet and its before/after lifecycle remain unchanged.
- Required run/rest, date, distance, duration, and save behavior are unchanged.
- V0.8 free-text consolidation remains unchanged.
- This is presentation/interaction restructuring only; Formal Current is unchanged.
