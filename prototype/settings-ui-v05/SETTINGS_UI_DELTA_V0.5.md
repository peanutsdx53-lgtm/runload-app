# Settings UI Prototype V0.5 — Complete New-App Settings

Date: 2026-09-18
Status: PROTOTYPE ONLY / FORMAL CURRENT UNCHANGED

Closed gaps:
- Text-size setting is represented.
- Only the adopted standard blue theme is shown; unapproved alternate color themes are not introduced.
- Optional reusable profile is represented:
  - running start period
  - self-assessed familiarity
  - running goals
  - optional height / weight / age band / sex context
- Profile context is explicitly nonnumeric for the 12-region result and is not a safety/diagnostic coefficient.
- Saved-shoe management is represented.
- Data management is represented:
  - backup export
  - backup file selection / review-before-restore
  - full local-data deletion confirmation
- About / product boundary is represented.

Prototype behavior:
- UI interactions work for review.
- Backup/restore/delete do not mutate real prototype data.
- Production integration will connect these controls to the already-existing Current storage services.

Explicitly absent:
- Notebook.
- session-RPE.
- unapproved color-theme variants.
- diagnosis, safety/readiness, or injury-risk controls.

Formal Current V1.16 / App V1.5R2 unchanged.
