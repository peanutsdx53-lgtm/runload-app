# Plan UI Prototype V0.1

Date: 2026-09-18
Status: PROTOTYPE ONLY / FORMAL CURRENT UNCHANGED

## Goal
Make planning feel like preparing the next run, not completing a long analysis workflow.

## Main visible inputs
- 予定日
- 走行 / 休養
- 距離
- 実走予定時間
- コース名

## Existing functions retained as secondary disclosure
- previous-record starting point
- smaller distance/time starting point
- rest starting point
- running format
- grade knowledge
- surface
- previous-record condition comparison
- saved-plan review and edit/use-for-record actions

## Continuity
The Home-approved user-authored "次のランで確認したいこと" is shown as context only.
Plan does not generate a new instruction or recommendation.

## Meaning boundary
Preset choices are editing starting points, not prescriptions or safety/readiness judgments.
Unknown course conditions remain unknown.

## Not included
- Notebook
- deletion action in prototype UI
- session-RPE
- integrated risk/load score

## Unchanged
Formal Current V1.16 / App V1.5R2, Record V0.9, Result V0.10, History V0.7, Home V0.2, repository root.
