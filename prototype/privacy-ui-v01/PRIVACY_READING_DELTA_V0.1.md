# Privacy / Reading Prototype V0.1

Date: 2026-09-18
Status: PROTOTYPE ONLY / FORMAL CURRENT UNCHANGED

Privacy V0.1:
- Explains local browser storage in plain language.
- Separates temporary in-progress data from saved data.
- States that RunLoad does not automatically upload saved records, consultation content, or GPX data.
- External sites / phone links open only by user action.
- Backup is user-initiated; automatic cloud upload is not assumed.
- App-side deletion does not delete files already exported to the device.
- New app scope: records created after the new app release only.
- No legacy compatibility / migration UI is introduced.

Reading V0.1:
- Replaces the very long Current column presentation with a compact hub.
- Shows one contextual recommendation from Result.
- Provides category filters.
- Uses 9 representative articles from the Current App knowledge set.
- Article detail opens in an in-page sheet instead of navigating through a long article index.
- Content remains general information; no diagnosis, prescription, safety/readiness, or injury-risk conclusion.
- session-RPE content is intentionally excluded from this prototype.

Candidate routes:
- More V0.3 -> Privacy V0.1 / Reading V0.1.
- Settings V0.3 -> Privacy V0.1.
- Activation V0.6 -> Reading V0.1.
- Home V0.12 / Result V0.20 / Consultation V0.2 / Public Support V0.2 aligned for review.
- Active root remains unchanged until user confirmation.

Explicitly absent:
- Notebook.
- session-RPE.
- legacy-data migration.
- automatic external sharing.

Formal Current V1.16 / App V1.5R2 unchanged.
