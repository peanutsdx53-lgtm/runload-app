# Consultation / Public Support Prototype V0.1

Date: 2026-09-18
Status: PROTOTYPE ONLY / FORMAL CURRENT UNCHANGED

Consultation V0.1:
- Two explicit sharing routes:
  1. 短く見せる
  2. 文書でまとめる
- Consultation target and question are consultation-only state.
- User chooses which saved information to include in the short memo.
- No automatic sending.
- Report separates:
  - consultation question
  - run facts
  - subjective/body record
  - selected regional Reference-100
  - distance as a separate run fact
- Regional value is described only against that region's fixed reference 100.
- Distance is not multiplied into the regional value.
- Report can be printed / saved as PDF by the browser.

Public Support V0.1:
- Separate from RunLoad result interpretation.
- RunLoad numeric results do not determine urgency.
- Emergency entry: Japan 119.
- #7119 official FDMA guidance is linked and explicitly described as region-dependent.
- MHLW 医療情報ネット（ナビイ） is linked for medical institution search.

Candidate navigation:
- Activation V0.5 -> Consultation V0.1.
- More V0.2 -> Consultation V0.1 / Public Support V0.1.
- Settings V0.2 / Home V0.11 / Result V0.19 aligned for candidate review.
- Active root is not changed until user confirmation.

Explicitly absent:
- Notebook.
- session-RPE.
- diagnosis.
- safety/readiness/injury-risk score.
- automatic selection of who the user should consult.
