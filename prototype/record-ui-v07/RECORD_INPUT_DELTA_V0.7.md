# RunLoad Record Input UI Prototype V0.7 — Intuitive fatigue flow

- Remove PRE / POST / ROF-J from the primary user-facing interaction.
- User-facing states are "走る前の疲労感" and "走った後の疲労感".
- Replace the select box with a 0–10 integer range control.
- Official Japanese descriptor anchors are shown only at 2,4,6,8,10.
- Odd values receive no RunLoad-created descriptor.
- The current screen shows only one question at a time.
- After recording the before-run value, the same entry becomes "走った後を記録".
- A secondary path remains for users who already finished running: "走った後だけ記録".
- ROF-J is retained only in the optional scale-information area.
- No session-RPE is introduced.
