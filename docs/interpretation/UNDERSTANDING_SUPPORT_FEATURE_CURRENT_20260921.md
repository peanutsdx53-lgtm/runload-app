# 結果理解支援機能 — Current機能仕様

Date: 2026-09-21
Status: FINALIZED
Scope: RunLoad application / Current update

## Current記載用要約

**必要性:** 結果画面で2つの結果を表示するだけでは、初心者ランナーが「どこを見るか」「何が分かるか」「次に何を確認するか」まで整理できるとは限らない。そのため、計算結果を変えずに、保存済みの結果を理解しやすい順序へ整理する機能が必要である。

**機能:** 保存済みの結果と比較可能な過去記録を用い、注目点、比較、分かること、分からないこと、次に確認することを段階的に提示する。自由回答型AIではなく、定めたルールに従って同じ入力から同じ整理結果を返す。

**役割:** 計算側は結果を生成し、本機能は生成済み結果の理解を支援する。診断、傷害リスク予測、安全・危険判定、走る／休む判断、トレーニング処方、因果推論は行わない。

## 1. なぜこの機能が必要か

RunLoadの結果画面は、部位別結果と主観的な疲労情報という2つの結果を正しく表示することが主目的である。

一方、初心者ランナーは、結果が表示されても、
- どこを見るべきか
- 前回や基準との違いをどう読むか
- 何が分かり、何は分からないか
- 次回どこを確認すればよいか

を自分で整理できない場合がある。

本研究の目的は、数値を提示するだけでなく、初心者ランナーの自己理解と自己判断を支援することである。そのため、計算結果を変更せず、保存された結果を理解可能な形へ整理する機能が必要である。

## 2. どのような機能か

本機能は、保存済みの結果を読み取り、利用者が結果を理解するための順序へ整理する決定論的な支援機能である。

主な処理:
1. 今回の記録で注目する情報を1つに絞る。
2. 必要に応じて、同じ部位の比較可能な過去記録またはその部位自身の基準との位置関係を示す。
3. 部位別結果と主観的な疲労情報を別の尺度として扱う。
4. 条件と結果が同時に変化しても、原因として結び付けない。
5. 「今回理解できること」「まだ分からないこと」「次に確認すること」を分ける。
6. 必要に応じて、履歴、条件比較、予定、共有、読みもの等の既存機能へつなぐ。

通常画面では一度に多くの情報を出さず、利用者が確認したい内容を段階的に選ぶ。

## 3. 計算機能との役割分担

計算側:
- 保存結果を生成する。
- 部位別結果の計算規則を保持する。
- 主観的な疲労情報を既存仕様に従って保持する。

結果理解支援側:
- 計算済み・保存済みの情報だけを読み取る。
- 計算結果を再計算、補正、上書きしない。
- 結果の意味を利用者が確認できる順序へ整理する。

結果画面は結果表示を主役とし、本機能は結果表示後に必要な場合だけ利用する派生機能として扱う。

## 4. 入口

主入口:
- ホームの最新走行記録: 「結果を理解する」
- 結果画面の2つの結果表示後: 「今回の結果を理解する」

文脈入口:
- 履歴の選択記録
- 部位詳細

画面メニューには重複入口を置かない。

旧 `#/activation` URLは、既存リンク破損を防ぐため新しい結果理解画面へ転送する互換処理だけを残す。旧画面本体は保持しない。

## 5. 扱う情報

- 今回の保存記録
- 保存済み部位別結果
- 比較条件が一致する過去の保存結果
- 主観的な疲労情報
- 保存された走行条件
- 既存の次回確認メモ
- 既存のサポート判定

比較可能性が確認できない記録を直接比較しない。

## 6. 行わないこと

本機能は以下を行わない。

- 診断
- 傷害リスク予測
- 安全・危険判定の新規生成
- 走る／休む判断
- 距離や時間などのトレーニング処方
- 条件と結果の因果推論
- 部位間の順位付け
- 生成AIによる自由文回答
- 新しい永続データ領域の追加
- 計算CoreやROF-J Coreの変更

既存のサポート判定がある場合は、それを再解釈せず優先表示する。

## 7. 表示方針

利用者向け画面では内部名称や研究上の実装名を表示せず、
- 結果を理解する
- 結果の確認
- 今回の確認
- この読み方の根拠

など、操作後に何ができるかを示す表現を使用する。

通常の強調に危険色を使わない。動きは短い一回のみとし、Reduced Motionでは同じ最終状態を静止表示する。

## 8. 安全上の追加対策

身体記録内の相談・安全情報は、現在の入力で「相談したい内容を残す」が選択されている場合だけ保存・判定対象にする。

以前の下書き等に残った非表示の安全項目が、通常記録へ混入しないようにする。

## 9. 実装上残すもの / 削除するもの

残す:
- 結果理解用の決定論的Core
- 表示層
- 結果理解画面
- 必要なCSS
- ホーム / 結果 / 履歴 / 部位詳細からの文脈入口
- 旧URLからの最小互換転送
- 専用回帰テスト

削除:
- 退役した旧結果活用画面本体
- 画面メニューの重複入口
- 旧画面を前提とする不要なruntime参照

本機能は以下をすべて満たした時点で完全終了とする。

- 不要runtime削除済み
- 入口整理済み
- 公開文言整理済み
- PWA/runtime SHA整合
- 保護Core byte-identical
- App Sourceの既存テスト + 本機能テストを全件実行し0 failure
- JS/MJS全構文検査0 failure
- Current自己検証PASS
- Public AppとApp Source runtimeの整合確認
