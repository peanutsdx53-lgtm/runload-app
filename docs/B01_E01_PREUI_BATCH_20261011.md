## B-01 — proven-unreachable CSS component families

The independent script counted 111 stylesheets. Source-only literal comparisons previously reported hundreds of unknown class selectors, but unknown does **not** mean unused: dynamic state suffixes and media/DOM context matter. This batch instead reviewed the following seven complete component families: `interpretation-pc`, `mobile-photo`, `report-sheet`, `share-viewer`, `report-period`, `report-section`, `workspace-navigation`. None of these names appears in current executable JavaScript/HTML, including app entry, service worker and both platforms. Unlike `home-state--*`, `mobile-home-ambient--*`, or `status-label--*`, they have no live runtime block/prefix generator in any current code path.

PostCSS selector-level deletion removed **215 complete unreachable CSS rules**, pruned **9 dead selectors from mixed rules**, saved **34,621 bytes** across 12+ existing stylesheets, and deliberately retained all 111 stylesheet assets, media settings, and other live selectors. The negative pre-remediation test failed, then passed when the families were removed. `tests/b01UnreferencedCssFamilyGuard.test.mjs` rejects either newly introduced runtime references to a retired family or residual orphan family styles. Existing `consultationBaselineParity.test.mjs` failed in the preliminary 10-family candidate because `share-preview` is part of its explicitly protected visual contract. Accordingly that change was *reverted before production*, and `share-preview`, `about-tags` and `history-records` families were excluded after independent test/reference confirmation. Regression now fully passes.

**No general CSS non-use is asserted** for the remaining class names without literal occurrences. The post-removal candidate's independent conservative scan still counted 267 such selectors among 1,742 distinct classes; dynamic states, historical visual contracts, and cross-route CSS may account for them. B-01 therefore remains **PARTIAL** pending a complete dynamic CSS semantics/class-state review. Do not remove those selectors from simple absence in JS source.
